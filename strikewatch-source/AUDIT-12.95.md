# Build 12.95 – desktop recruitment action consistency

Build 12.95 extends the recruitment card action treatment to desktop card views. The shortlist control now appears as a compact square star button on desktop recruitment cards, aligned alongside the other card actions to mirror the tighter mobile treatment from Build 12.94.

## What changed
- desktop/front recruitment card actions now use a compact shortlist star button
- desktop/front recruitment card replaces the smaller report action wording with a clearer Details action
- desktop/back recruitment card actions now include the same compact shortlist star button
- desktop action grids were rebalanced so utility and primary actions align more cleanly
- standalone build metadata updated to 12.95

## Notes
- mobile recruitment summary alignment from Build 12.94 remains in place
- scouting, reports, negotiation flow, save schema 19 and diagnostics schema 1 are unchanged
