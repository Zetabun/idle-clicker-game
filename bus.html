Data source

Live positions come from the Department for Transport's Bus Open Data Service. Registration is free. BODS doesn't send CORS headers, so a browser needs a proxy in front of it — put yours below, or run this file through one.

Register at data.bus-data.dft.gov.uk, then find the key in your account. Held in memory only — nothing is stored or sent anywhere except the feed.
The feed URL gets appended, encoded. Leave empty to call BODS directly — that only works outside a browser sandbox.
